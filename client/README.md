# MyTechZ - Client

The frontend application for [MyTechZ](https://mytechz.com), built with [Next.js 15](https://nextjs.org) and Tailwind CSS.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Language:** JavaScript
